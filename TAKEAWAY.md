Decision Tree Pass/Fail Prediction

This project demonstrates a simple decision tree classifier using scikit-learn.  
The dataset contains study hours and pass/fail labels for students.  
The model uses entropy and information gain to decide splits.

How to Run
1. Install requirements: pip install pandas scikit-learn
2. Run the notebook in Jupyter.
3. See predictions and tree rules printed in the console.

Takeaway
Decision trees use entropy to measure uncertainty and information gain to choose the best split.  
In this example, study hours are used to predict whether a student passes or fails.
